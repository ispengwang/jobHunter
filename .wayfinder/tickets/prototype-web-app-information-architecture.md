# Prototype web app information architecture

## Question

How should Candidate Profile settings, daily Dashboard actions, job details, application history and exception states fit into the existing local web app without turning it into an opaque automation console?

## Known context

- The user wants to extend the current web app.
- Candidate Profile data must be auto-filled from the resume and later editable.
- The Dashboard must serve both historical record-keeping and day-to-day action selection.
