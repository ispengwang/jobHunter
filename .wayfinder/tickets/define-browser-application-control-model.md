# Define browser application control model

## Question

Which platforms should be supported first, what does an automatic broad or targeted submission do from start to finish, and when must the browser hand control to the user?

## Known context

- The user wants actual automatic application capability, not only material generation.
- Browser work uses the user's already authenticated ChatGPT Atlas session.
- CAPTCHAs and platform-security controls must never be bypassed; their manual-takeover experience is still undecided.
